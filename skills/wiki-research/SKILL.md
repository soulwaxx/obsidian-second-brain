# Bounded Wiki Research

Follow [focused workflows](../wiki/references/focused-workflows.md) and the evidence and authoring rules in [the wiki skill](../wiki/SKILL.md), [research discipline](../wiki/references/research-discipline.md), and [authoring standards](../wiki/references/authoring-standards.md).

Define the question and limits, inspect relevant wiki pages first, then use only selected local sources or research tools actually available in the current task. Keep source-backed claims, inference, contradictions, and unanswered questions distinct. Cite only evidence actually inspected. Answer without writing unless the user explicitly requested filing; then make only a relevant, bounded canonical-page update. The package does not provide web search, web fetching, or web/media adapters. For a user-selected local UTF-8 text file, an explicitly requested immutable source capture is available through the separate reviewed capture workflow; it preserves the original bytes and hashes and can link selected existing wiki pages. Capture is optional and does not itself make or file claims. Use a reviewed recoverable batch only for larger coordinated wiki edits, not for ordinary small changes. See [focused workflows](../wiki/references/focused-workflows.md) for the available commands and limits.
